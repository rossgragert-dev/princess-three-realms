# Narration clips go here
Drop `<key>.m4a` (AAC, needed for iPad Safari) and `<key>.ogg` for each line key listed in `docs/narration_manifest.json`
(also `docs/AUDIO_SCRIPT.md`). No rebuild of the game is needed: copy the files into `assets/audio/narration/` of the deployed site
and refresh. Missing clips are fine; the game falls back to a pulsing arrow and captions.
